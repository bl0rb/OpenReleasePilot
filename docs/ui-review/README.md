# UI-Review: Bildschirmfotos

OpenReleasePilot 0.3.4, aufgenommen am 14.10.2026 aus der installierten App (Fenster 1280 × 1040 pt, Retina, helles Erscheinungsbild).

| Bild | Bereich |
|---|---|
| `01a-repositories-liste` | Repositories: Liste mit Entscheidungskarte oben |
| `01b-repositories-liste-auswahl` | Repositories: ein Repository ausgewählt, „Pflegen (1) …“ aktiv |
| `02a/02b-repository-detail-*` | Repository-Detail nudgit (durch offenen Auftrag gesperrt) |
| `03-dialog-repositories-hinzufuegen` | Dialog „Repositories auswählen“ |
| `04-dialog-pflegen` | Dialog „Pflegen“ (Auftrag anlegen) |
| `05a/05b-repository-detail-mit-prs-*` | Repository-Detail Gartenamt mit Dependabot-PRs und Verwaltung |
| `06/06b-dialog-inhaltsziel-*` | Dialog „Inhaltsziel hinzufügen“ (README/Wiki) |
| `07-laeufe-liste` | Läufe: offene und bisherige Aufträge |
| `08a–08d-auftrag-offen-*` | Offener Auftrag: Ergebnis, Claudes Zusammenfassung, Freigabe, Log |
| `09a–09c-auftrag-abgeschlossen-*` | Abgeschlossener Auftrag: Übersicht, Pflegeplan aufgeklappt, Ende |
| `10a/10b-website-*` | Website: Ablauf (Precheck, Update, Upload, Verify), Produkte, Update-Aufgaben |
| `11-dialog-neues-produkt` | Dialog „Neues Produkt aufnehmen“ |
| `12a/12b-einrichtung-*` | Dialog „Einrichtung“ |

Nicht aufgenommen, weil schon das Öffnen etwas auslöst oder es nur ein Bestätigungsdialog ist: „Auftrag beenden …“, „Aus der Verwaltung entfernen …“, „Sicherheit prüfen“ (Ergebnis) und die „Starten“-Schritte im Website-Bereich.
